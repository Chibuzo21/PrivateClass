We have client, sever side and database in all fullstack applications.
React runs on the client side. client is basically the user's device/browser interacting with your application. client handles things like displaying UI, buttons, forms, animations, browser apis, local storage etc.
The server is where your application performs operations that shouldnt happen directly in the browser. it handles things like api requests, authentication, secure usage of api keys, communicating with external services, communication with the database etc
